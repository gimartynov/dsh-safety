# dsh-safety

Два небольших плагина для [DeepSeek Harness](https://deepseek.com), которые закрывают две дыры,
которых не закрывают штатные настройки:

| Плагин | Что решает | Токены |
| --- | --- | --- |
| **dsh-guard** | агент не может удалить или перезаписать то, что вы пометили как ценное; команды, переписывающие историю git, уходят в обычный запрос подтверждения | 0 |
| **dsh-snapshots** | локальные точки восстановления проекта: `/snap`, `/snapshots`, `/rollback`, авто-снапшот перед изменяющими вызовами | 0 |

Оба плагина работают на host-стороне, не добавляют инструментов в промпт и не вызывают модель.
Песочницу и пресеты прав они не подменяют — добавляют ещё один независимый слой.

## dsh-guard

Проверяет каждый вызов инструмента синхронно, по строке команды и путям:

- **deny** — мутирующая команда (`rm`, `mv`, `cp`, `touch`, `sed -i`, `tee`, редирект…) или запись
  касается защищённого пути; плюс отдельный список катастрофических шаблонов (`rm -rf /`,
  `mkfs`, `dd of=/dev/disk…`);
- **ask** — `git reset --hard`, `git clean -fd`, `git push --force`, `git stash drop`,
  `rm -r`, `shred`, `truncate -s 0`;
- **allow** — всё остальное; чтение защищённых путей не блокируется.

```yaml
# профиль: cordis.patch.yml
- id: dsh-guard
  config:
    protect:
      - '~/MyGame'
      - '~/Books'
    allowWrite:
      - '~/MyGame/Builds'   # сюда писать можно
```

По умолчанию защищены `~/.dsh`, `~/.ssh`, `~/.aws`, `~/.gnupg`, `~/.config/gh`,
`~/Library/Keychains`. Отказы и запросы пишутся в `~/.dsh/guard-audit.jsonl`.
Подробности — [packages/dsh-guard/docs/DETAIL.md](packages/dsh-guard/docs/DETAIL.md).

## dsh-snapshots

Теневой git-репозиторий в `~/.dsh/snapshots/`: ваш `.git` не трогается, снапшоты никуда не уезжают.

```
/snap [метка]                  снять точку
/snapshots [N]                 список последних точек
/rollback <номер|ref> [--clean]  вернуть файлы (--clean удаляет и созданные после)
```

Перед каждым откатом автоматически снимается `pre-rollback`-снапшот, поэтому откат тоже обратим.
Авто-снапшоты перед `rm`/`mv`/`write`/`edit` идут с кулдауном, чтобы не тормозить работу.
Подробности — [packages/dsh-snapshots/docs/DETAIL.md](packages/dsh-snapshots/docs/DETAIL.md).

## Установка

```bash
dsh plugin add /path/to/packages/dsh-guard
dsh plugin add /path/to/packages/dsh-snapshots
```

Или через интерфейс: **Настройки → Плагины → Установить бандл** (указать каталог пакета).
Ставить по одному и перезапускать приложение между установками: сломанный бандл
уводит приложение в аварийный режим.

Зависимость `@deepseek-ai/schemastery` предоставляется самим Harness.

## Проверено

Тесты гоняются без DSH, на чистом Node с заглушкой контекста:

```bash
cd packages/dsh-guard    && ELECTRON_RUN_AS_NODE=1 "$DSH_NODE_EXECUTABLE" test/guard.test.mjs
cd packages/dsh-snapshots && ELECTRON_RUN_AS_NODE=1 "$DSH_NODE_EXECUTABLE" test/snapshots.test.mjs
```

Тесты не требуют `node_modules`: если `@deepseek-ai/schemastery` не установлен, плагин берёт
встроенную заглушку схемы (в самом DSH всегда используется настоящая).

- guard: 13/13 (отказ на `rm -rf` по защищённому пути, разрешение чтения, `allowWrite`,
  защита по `cwd` для относительных целей, катастрофические шаблоны, `ask` на переписывание истории,
  редирект в `/dev/null` не считается записью, неизвестный `cwd` не выдумывает защищённый путь,
  текст внутри heredoc не считается командой);
- snapshots: 9/9 (создание, «no changes», список, откат с `--clean` и без, неизвестный снапшот,
  авто-снапшот только на изменяющих вызовах, теневое хранилище вне проекта, честная ошибка
  без настроенных корней).

Живьём в DSH проверено: отказ на `rm -rf ~/MyGame/...`, авто-снапшот (742 файла, 31 МБ,
исключения работают) и горячая перезагрузка плагинов без перезапуска приложения.

macOS 26 (arm64), macOS 15+, Linux. Требуется `git` в `PATH` (для снапшотов).
